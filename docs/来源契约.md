# 资料提供方的格式

`/stations/cards.csv` 是装卡与转移记录。generation 是站点内装卡轮，serial 是卡的物理号。source_generation 非空时表示同一卡从该轮转入，具体可从新站领取的曝光由 `/camera/rotated.json` 的 moved 逐条列出。`/camera/index.json` 的条目依次给站、装卡轮、片号、曝光 ID、字节数、预计覆盖分钟和下载位置。摄像站可以保留卸卡前的待传缓存，装卡更换时间与缓存覆盖时间各自记录。`/camera/rotated.json` 的 overwrites 给实际覆盖观察，moved 的末列是转存记录的观察分钟。转移行用原曝光 ID 保持身份。资料站留有固定的演练文件，每个资源实际支持 HTTP Range。能否在当班继续领到，需结合覆盖观察与各站联通时段查看。
`/archive/inbox.json` 明确已签收的字节范围与是否预览。 `/crew/route.json` 给各点下次可驻留时段、每分钟可传字节、领卡额度和站点之间步行分钟，所有时间采用值班日分钟数。 `/crew/transport.json` 提供上一班携带承诺和实际签收。
归档回执前两项为曝光和原始装卡轮，接下来是左闭右开的字节范围、件别和签收指纹别名。late_observed_at 是后续回执可见的分钟。HTTP Range 则按协议使用闭区间。值班日时间也适用于带卡交接的观察记录。实际签收和归档接收由两处分别记录。
