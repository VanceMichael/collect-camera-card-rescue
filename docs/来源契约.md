# 资料提供方的格式

`/stations/cards.csv` 是装卡与转移记录。generation 是站点内装卡轮，serial 是卡的物理号，source_generation 非空时为随原组转移的既存数据。 `/camera/index.json` 的条目给站、装卡轮、号、曝光 ID、字节数、预计覆盖分钟、下载位置。 `/camera/rotated.json` 给实况覆盖或移卡，转移行用原曝光 ID 保持身份。每个资源实际支持 HTTP Range，未写完的尾段以当轮已发布范围为限。
`/archive/inbox.json` 明确已签收的字节范围与是否预览。 `/crew/route.json` 给各点下次可驻留时段、每分钟可传字节、领卡额度和站点之间步行分钟，所有时间采用值班日分钟数。 `/crew/transport.json` 提供上一班携带承诺和实际签收。
归档回执前两项为曝光和原始装卡轮，接下来是左闭右开的字节范围、件别和签收指纹别名。HTTP Range 则按协议使用闭区间。
